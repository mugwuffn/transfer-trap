# Changelog

## v0.3 — Local progression update
- Added daily streak tracking.
- Added Football Passport for correctly identified players.
- Added nine achievements and unlock notifications.
- Added local profile stats for best daily score, completed games and unique players.
- Added explicit UI note that global leaderboards, mini-leagues and live head-to-head are planned and not active.
- Updated README and product specification to distinguish implemented features from backend-dependent roadmap items.

## Known limitations
- Profile and score storage are local to the browser.
- The question bank is still a 17-question prototype and has not been verified as comprehensive worldwide/all-era content.
- No active account system, global leaderboard, mini-league or live multiplayer backend.
